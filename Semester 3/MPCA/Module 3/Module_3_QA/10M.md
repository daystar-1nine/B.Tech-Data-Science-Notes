### Q1. Explain the internal architecture of 8086 in detail (BIU, EU, registers, flag register) with a neat labeled diagram.

```
+-----------------------------------------------------------------------------------+
|                            BUS INTERFACE UNIT (BIU)                               |
|                                                                                   |
|  Segment Registers:   [ CS: Code ] [ DS: Data ] [ SS: Stack ] [ ES: Extra ]       |
|                       Instruction Pointer: [ IP ]                                 |
|                                   |                                               |
|                                   v                                               |
|                       20-Bit Physical Address Generator Adder                     |
|                                   |                                               |
|                                   v                                               |
|                   6-Byte Instruction Queue  [ Q1 | Q2 | Q3 | Q4 | Q5 | Q6 ]          |
+-----------------------------------|-----------------------------------------------+
                                    | Internal System Bus
+-----------------------------------|-----------------------------------------------+
|                            EXECUTION UNIT (EU)                                    |
|                                                                                   |
|  General Registers:   [ AH | AL ] (AX)   [ BH | BL ] (BX)                         |
|                       [ CH | CL ] (CX)   [ DH | DL ] (DX)                         |
|  Pointers & Indexes:  [ SP: Stack Ptr ]  [ BP: Base Ptr ]                         |
|                       [ SI: Src Index ]  [ DI: Dest Index ]                       |
|                                                                                   |
|  Control Logic <---> 16-Bit ALU <---> 16-Bit Flag Register                        |
|                                       [O|D|I|T|S|Z|A|P|C]                         |
+-----------------------------------------------------------------------------------+
```

#### 1. Bus Interface Unit (BIU)
- **Segment Registers:** Four 16-bit registers (`CS`, `DS`, `SS`, `ES`) storing segment base addresses.
- **Instruction Pointer (IP):** Holds the 16-bit offset of the next instruction byte to fetch.
- **Instruction Queue:** 6-byte FIFO buffer prefetching instructions during idle memory cycles.

#### 2. Execution Unit (EU)
- **ALU (16-bit):** Performs arithmetic and bitwise logic operations.
- **General Purpose Registers:** `AX` (Accumulator), `BX` (Base), `CX` (Counter), `DX` (Data).
- **Pointer/Index Registers:** `SP`, `BP`, `SI`, `DI`.
- **16-bit Flag Register (9 Active Flags):**
  - **Status Flags:** `CF` (Carry), `PF` (Parity), `AF` (Aux Carry), `ZF` (Zero), `SF` (Sign), `OF` (Overflow).
  - **Control Flags:** `IF` (Interrupt Enable), `DF` (Direction Flag), `TF` (Trap Flag).

### Q2. Explain the functional pin diagram of 8086 microprocessor in detail, describing the function of each pin group (address/data bus, control signals, power supply).

```
                      +---  --- +
                 GND  | 1    40 | VCC (+5V)
             AD14 <-> | 2    39 | <-> AD15
             AD13 <-> | 3    38 | -> A16/S3
             AD12 <-> | 4    37 | -> A17/S4
             AD11 <-> | 5    36 | -> A18/S5
             AD10 <-> | 6    37 | -> A19/S6
              AD9 <-> | 7    34 | -> BHE'/S7
              AD8 <-> | 8    33 | -> MN/MX'
              AD7 <-> | 9    32 | -> RD'
              AD6 <-> | 10   31 | -> HOLD (RQ/GT0')
              AD5 <-> | 11   30 | -> HLDA (RQ/GT1')
              AD4 <-> | 12   29 | -> WR' (LOCK')
              AD3 <-> | 13   28 | -> M/IO' (S2')

              CLK --> | 19   22 | <- READY

                      +--------+
```

1. **Multiplexed Address/Data Bus (AD0 - AD15):** Time-multiplexed lines carrying lower 16-bit memory address during `T1` and 16-bit data during `T2-T4`.
2. **Address/Status Lines (A16/S3 - A19/S6):** Upper 4-bit address lines multiplexed with CPU status indicators.
3. **Minimum Mode Control Signals:**
   - `ALE` (Address Latch Enable), `RD'`, `WR'`, `M/IO'`, `DT/R'`, `DEN'`, `INTA'`.
4. **Maximum Mode Status Lines:**
   - `S0', S1', S2'` decoded by 8288 bus controller into memory/IO read-write commands.
5. **System Controls & Power:** `VCC` (+5V), `GND`, `CLK` (Clock input 5-10MHz), `RESET`, `READY`, `NMI`, `INTR`.

### Q3. Explain memory segmentation and banking in 8086 in detail with physical address calculation examples. Also explain why segmentation is used.

#### 1. Why Memory Segmentation is Used
- Allows a 16-bit CPU architecture with 16-bit registers to address **1MB (2^20 bytes)** of physical memory.
- Enables modular code relocation and dynamic memory protection between code, data, and stack spaces.

#### 2. Physical Address Calculation Formula & Example
```
Physical Address = (Segment Register × 16) + Offset
```

- **Example 1 (Instruction Fetch):** `CS = 3000H`, `IP = 0100H`
  ```
  Physical Address = (3000H × 16) + 0100H = 30000H + 0100H = 30100H
  ```
- **Example 2 (Data Read):** `DS = 4500H`, `BX = 0250H`
  ```
  Physical Address = (4500H × 16) + 0250H = 45000H + 0250H = 45250H
  ```

#### 3. Memory Banking System (Even & Odd Banks)

```
        1MB PHYSICAL MEMORY SYSTEM
       /                           EVEN BANK (512 KB)           ODD BANK (512 KB)
 Address Line A0 = 0          Bus High Enable BHE' = 0
 Data Bus D0 - D7             Data Bus D8 - D15
```
