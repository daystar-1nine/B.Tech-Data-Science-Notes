## 🌟 Overview

**DataSci Notes Studio** is an open-source, mobile-first academic study platform built specifically for **B.Tech Data Science** undergraduates preparing for university semester exams and GATE.

It features **98+ exam topics**, module-wise solved question banks (**2-Mark, 3-Mark, 5-Mark, and 10-Mark Q&A**), interactive **Rapid Revision Flashcards**, spotlight search (`Ctrl + K`), and 1-click **PDF downloads**.

---

## ✨ Key Features

- 📑 **5-Tier Exam Formulation Engine**:
  1. **Definition to Remember**: Concise technical statements for rapid understanding.
  2. **Structured Answers**: Complete step-by-step topic explanations for university exams.
  3. **Memory Keywords**: Highlighted core technical terminology.
  4. **Must-Write Points**: 5–7 mandatory scoring bullet points required by university examiners.
  5. **Quick Recall**: One-line memory flows for rapid recall before entering the exam hall.
- ⚡ **Rapid Revision Flashcards**: Interactive subject-wise digital flashcards for fast revision.
- 🔍 **Spotlight Search (`Ctrl + K`)**: Instant search across all 98+ notes, concepts, and questions.
- 📥 **1-Click PDF Downloads**: Download offline PDF copies for all major module topics.
- 📱 **Mobile-First Responsive Design**: Works seamlessly across iPhones, Android devices, tablets, and desktop displays.
- 🎨 **Adaptive Crimson & Cream Theme**: Dark Mode and Warm Cream Mode for comfortable night and day study sessions.

## 💻 Local Setup & Development

To run this portal locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/daystar-1nine/B.Tech-Data-Science-Notes.git

# 2. Navigate to project directory
cd B.Tech-Data-Science-Notes

# 3. Start local development server
python -m http.server 8080

# 4. Open in browser
# http://localhost:8080
```

To re-index new semester markdown notes:

```bash
python build_site_data.py
```

## 🤝 Contribution Guidelines

Contributions are welcome! If you would like to add notes for new semesters (Semester 1 to Semester 8) or improve existing question banks:

1. Fork the Repository.
2. Create a feature branch (`git checkout -b feature/AddSem4Notes`).
3. Add your Markdown notes in the respective `Semester X/Subject/Module Y/` folder.
4. Run `python build_site_data.py` to regenerate `notes_data.js`.
5. Commit and push your changes (`git commit -m "Add Semester 4 Notes"`).
6. Open a Pull Request!
